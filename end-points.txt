1 - create Role , role has name and permissions.
2- there is an end point to get permissions. 
 example of creating role: 1- {name: "Ali-Role": permissions: { action: ['Manage'], subject: 'All' }}
2- create user and assign them the role, user (sub-admins) will have same format as mobile app, except passowrd will be generated by user when they login again.
3- create a product, a product can have name (mandatory),short description (mandatory), long description, image, and sections (title + text)
4- a product can be a child of another product (so assgin parent product ).
5- a product can be featured product, (toggle)
6- create a promotion, which has title, long description, image and link (https) or linked to a product.
7- super admin will be the first to login, but then have to create sub users. 
8- you can get orders(purchases) of users, orders will have a list of product purchased, and date, total, etc..
9- you can see all users created from the application (add pagination).
10- under a user you can see their purchases.
11- you can see a list of sub admins, and their roles.
12- you can see what the sub admins did (history of sub admins actions.)
